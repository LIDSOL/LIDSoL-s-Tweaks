*** TODO Quick Text [0/2] :shell:
- Descripción:
  - Un atajo de teclado (Ctrl+Super+i, aunque es personalizable) abre una ventana de diálogo desde la cual podemos escribir texto que se insertará en algún alchivo de texto plano de nuestra preferencia; podemos configurar un prefijo o sufijo al texto insertado. * 0. La propuesta de proyecto
** Inserta título aquí
Las extensiones de GNOME dependen de APIs internas sujetas a cambios, esto genera obsolescencia: las actualizaciones del escritorio /pueden romper/ las extensiones.

En este proyecto se estudiará el código de extensiones obsoletas y sin mantenimiento, con el objetivo de modernizarlas y unificarlas en una única extension compatible con GNOME SHELL 50.

El resultado esperado es una extensión que sea estrictamente modular, con bajo acoplamiento, que gestione de forma centralizada las señales, "lazy loading" y optimizada. Su arquitectura debe facilitar el mantenimiento y se validará mediante métricas de rendimiento, estabilidad y con control explícito del ciclo de vida de cada componente.
